# لوحة مطابقة المرتجعات — ARRIVE

لوحة بنفس تصميم لوحة الشكاوى (ARRIVE Design System V2.0) لمطابقة المرتجعات المرسلة من الفروع مع المستلمة.

## التشغيل
- ملفات ثابتة بلا بناء: ارفع المجلد كما هو على GitHub وفعّل GitHub Pages (Settings → Pages → Branch: main / root)، أو افتح `index.html` مباشرة.
- يحتاج اتصالًا بالإنترنت لخط Cairo/Inter ومكتبة Chart.js (cdnjs).

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | هيكل الصفحة |
| `arrive-tokens.css`, `arrive-ui.css` | نظام التصميم (نفس لوحة الشكاوى دون تعديل) |
| `arrive-returns.css` | إضافات خاصة بهذه اللوحة |
| `data.js` | البيانات: لقطة من ورقة «شهر 10» بتاريخ 26/10/2026 |
| `core.js` | معادلات الحساب (المرسل، غير المستلم، النسبة) |
| `app.js` | الفلاتر والرسوم والجداول |

## تعريفات الحساب
- نسبة المطابقة = (المرسل − غير المستلم) ÷ المرسل.
- غير المستلم: الافتراضي كما هو في عمود الشيت. الخيار البديل: `min(المرسل, max(0, المرسل − (المستلم − غير المدرجة)))`.
- «غير مدرجة»: شحنات مستلمة لا يوجد لها إرسال مسجّل.
- الصفوف الأصلية لم تُعدّل. أكواد `flags` في `data.js` وسم جودة فقط، واستبعاد «مكرر_متطابق» و«متابعة_متبقي» اختياري من الفلاتر.

## الربط المباشر بالشيت (Live)
1. افتح الشيت → Extensions → Apps Script، والصق محتوى `apps-script/Code.gs` (يقرأ تبويب `gid=1064670621` فقط، قراءة فقط ولا يعدّل الشيت).
2. Deploy → New deployment → Web app: Execute as **Me**، Who has access **Anyone** → انسخ الرابط المنتهي بـ `/exec`.
3. ضع الرابط في `LIVE_URL` داخل `live.js` وارفع التعديل.
- اللوحة تسحب الشيت عند الفتح، وكل دقيقتين، وعند العودة للتبويب. الفلاتر المختارة تبقى كما هي عند التحديث.
- إن ترك `LIVE_URL` فارغًا أو فشل الاتصال تظل اللقطة الثابتة في `data.js` تعمل (الشارة في الهيدر توضح الحالة).
- أسماء الفروع المختصرة تُستنتج تلقائيًا بمطابقة الصفوف مع اللقطة؛ أي فرع جديد يظهر باسمه من الشيت بعد حذف كلمة «فرع».
- وسوم الجودة (`flags`) تُحسب الآن داخل `core.js` (`OCT.flagRows`) وتطابق وسوم اللقطة الحالية في الصفوف الـ378.
- التواريخ: الرقم المساوي لـ 10 هو الشهر والآخر هو اليوم، فيُعالج اختلاف يوم/شهر وشهر/يوم؛ ويُتجاهل أي صف لشهر آخر.
- تنبيه: أي شخص لديه الرابط يستطيع قراءة الأرقام (Anyone). إن لزم تقييده يُضاف مفتاح في الرابط.

## تحديث البيانات يدويًا (بدون ربط)
استبدل المصفوفة في `data.js` بنفس الأعمدة: `sheetRow, date (YYYY-MM-DD), branch, sent, recv, status, unrecv, extra, flags`.

## تبويب «SLA المرتجعات» (جديد)
تبويب ثانٍ بجانب «مطابقة المرتجعات» في نفس الصفحة، ومنطق المطابقة لم يتغير (`app.js` و`core.js` و`data.js` و`live.js` و`report.js` كما هي).

| الملف | الدور |
|---|---|
| `sla.js` | منطق التبويب والفلاتر والرسوم (يعمل داخل IIFE بأسماء معرّفات تبدأ بـ `s`) |
| `arrive-sla.css` | شريط التبويبات وإضافات صغيرة فقط، على نفس نظام التصميم |
| `sla-data.js` | لقطة بتاريخ 26/10/2026 من شيت «Sla RTO» (40,119 صف، تابات 1-9 إلى 30-9)، تُحمّل عند فتح التبويب فقط |
| `apps-script/Code-SLA.gs` | سكريبت قراءة فقط يجمع التابات اليومية في JSON واحد مضغوط |

**الربط المباشر:** مشروع Apps Script مستقل مرتبط بشيت «Sla RTO» (غير شيت تقرير المرتجعات). الصق `Code-SLA.gs`، وانشره Web app (Execute as: Me، Access: Anyone)، وضع رابط `/exec` في `SLA_LIVE_URL` أعلى `sla.js`. التحديث كل 10 دقائق والتبويب مفتوح. إن بقي الرابط فارغًا تُستخدم اللقطة.

**التعريفات:**
- عمر المرتجع = تاريخ تقفيل المرتجع − تاريخ التقفيل. الافتراضي عمود الشيت، والبديل محسوب (فلتر «أساس حساب العمر»).
- حد الـ SLA فارغ افتراضيًا (لا حد معتمد). «داخل الحد» = العمر ≤ الحد، ولا يظهر أي حكم قبل إدخاله.
- البوليصات المتكررة بين التابات لا تُستبعد افتراضيًا (فلتر: كل الصفوف / آخر ظهور / أول ظهور).
- أسماء الفروع تُوحَّد للعرض فقط (جدول `BR_NAMES` في `sla.js`)، والاسم الأصلي يظهر في السجل. تاب 21-9 فيه عمود الفرع مكتوب فيه «تم الارتجاع للراسل» فيظهر الفرع «غير محدد بالمصدر».
- وسوم الجودة: تاريخ ناقص، عمر لا يطابق التواريخ، فرع غير محدد، بيك أب فارغ، بوليصة متكررة. وسم فقط ولا تُعدَّل أي قيمة.
