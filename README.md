# لوحة مطابقة المرتجعات — ARRIVE

لوحة بنفس تصميم لوحة الشكاوى (ARRIVE Design System V2.0) لمطابقة المرتجعات المرسلة من الفروع مع المستلمة.

## التشغيل
- ملفات ثابتة بلا بناء: ارفع المجلد كما هو على GitHub وفعّل GitHub Pages (Settings → Pages → Branch: main / root)، أو افتح `index.html` مباشرة.
- يحتاج اتصالًا بالإنترنت لخط Cairo/Inter ومكتبة Chart.js (cdnjs).

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | هيكل الصفحة |
| `arrive-tokens.css`, `arrive-ui.css` | نظام التصميم (نفس لوحة الشكاوى دون تعديل) |
| `arrive-returns.css` | إضافات خاصة بهذه اللوحة |
| `data.js` | البيانات: لقطة من ورقة «شهر 10» بتاريخ 26/10/2026 |
| `core.js` | معادلات الحساب (المرسل، غير المستلم، النسبة) |
| `app.js` | الفلاتر والرسوم والجداول |

## تعريفات الحساب
- نسبة المطابقة = (المرسل − غير المستلم) ÷ المرسل.
- غير المستلم: الافتراضي كما هو في عمود الشيت. الخيار البديل: `min(المرسل, max(0, المرسل − (المستلم − غير المدرجة)))`.
- «غير مدرجة»: شحنات مستلمة لا يوجد لها إرسال مسجّل.
- الصفوف الأصلية لم تُعدّل. أكواد `flags` في `data.js` وسم جودة فقط، واستبعاد «مكرر_متطابق» و«متابعة_متبقي» اختياري من الفلاتر.

## تحديث البيانات
البيانات حاليًا لقطة ثابتة وليست متصلة بالشيت. لتحديثها استبدل المصفوفة في `data.js` بنفس الأعمدة: `sheetRow, date (YYYY-MM-DD), branch, sent, recv, status, unrecv, extra, flags`.
تنبيه: تواريخ 3–8 أكتوبر في الشيت مكتوبة يوم/شهر وتواريخ 10–25 مكتوبة شهر/يوم، وقد وُحّدت كلها كتواريخ أكتوبر.
